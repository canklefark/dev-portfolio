export async function gate(options) with options { apiUrl, token, repository, sha, refName, runId }, apiUrl without a trailing slash, resolving to null when the deploy may proceed and otherwise to the refusal reason (a string). It prints its informational lines itself.
Two GET requests, in this order, each with headers accept application/vnd.github+json, authorization Bearer, x-github-api-version 2022-11-28 and a 15 second timeout; the second is made only when the first passes:
1. /repos/{repository}/compare/{sha}...main. body.status is identical, ahead (main is ahead of sha, so sha is an ancestor of main), behind or diverged; body.ahead_by counts the commits main is ahead. On main means identical or ahead.
2. /repos/{repository}/actions/workflows/ci.yml/runs?head_sha={sha}&per_page=100. body.workflow_runs is a list of runs with id, status, conclusion, event, created_at and head_repository.full_name. A run counts only when head_repository.full_name equals repository and event is push or workflow_dispatch (a pull request or fork run never counts, T-05-24). The newest counting run by created_at (the larger id on a tie) decides: status completed and conclusion success passes.
Printed lines: `deploy-gate: <sha7> is the tip of main` for identical; `deploy-gate: note: main is <n> commits ahead of <sha7>; Dokploy builds the tip of main, so the tag should be the tip` for ahead; `deploy-gate: ci run <id> succeeded for <sha7>`; the CLI then prints `deploy-gate: PASS` or `deploy-gate: FAIL (<reason>)`. Exit 0 for PASS, 1 for a refusal, 2 for a missing variable (names only on stderr) or a plain http GITHUB_API_URL outside loopback (no request made).
Refusal reasons (exact text, pinned by the tests): `<sha7> is not on main (compare status <status>)`; `compare answered <http status>`; `compare did not return a comparison status`; `compare request failed: <message>`; `no ci run found for <sha7>; ci skips documentation-only pushes, so start it with: gh workflow run ci.yml --ref <refName or the tag name>, wait for it to pass, then re-run this deploy with: gh run rerun <runId or this run id>`; `latest ci run <id> for <sha7> is <status>; wait for it to finish, then re-run this deploy`; `latest ci run <id> for <sha7> concluded <conclusion>`; `ci runs answered <http status>`; `ci runs did not return a run list`; `ci runs request failed: <message>`. sha7 is the first seven characters of the sha.
