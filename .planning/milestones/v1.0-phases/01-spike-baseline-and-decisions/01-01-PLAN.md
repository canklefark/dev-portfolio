  Prints "OK ROUTE" or "DIFF ROUTE: REASON" per route, then the summary line "compare: IDENTICAL/TOTAL identical". Exit 0 only when the route sets match and every route is identical; exit 1 otherwise; exit 2 on usage errors.

  Writes the allowlist JSON.
- node scripts/script-inventory.mjs check ALLOWLIST_JSON DIST_DIR (task 2)
  Prints "PASS ROUTE" or "FAIL ROUTE: REASON" per route, then "check: PASSED/TOTAL passed". Exit 0 only when every route passes.
- node scripts/script-inventory.mjs selftest BASELINE_DIST_DIR [ALLOWLIST_JSON]
  Runs mutation cases on temporary copies; prints "DETECTED CASE" or "MISSED CASE", then "selftest: N/TOTAL detected". Exit 0 only when every expectation holds.
- fetch is added by plan 01-03.

Route keys: index.html maps to "/", DIR/index.html maps to "/DIR", 404.html maps to "/404".

Inventory JSON: { "routes": { ROUTE: { "file": RELATIVE_PATH, "scripts": [ { "kind": "inline" | "external" | "data", "type": TYPE_OR_classic, "src": SRC_OR_null, "bytes": N, "sha256": "sha256-BASE64" or null } ], "counts": { "script", "inline", "external", "module", "data", "modulepreload", "preload", "stylesheet" } } } }
"script" counts executable scripts only (inline plus external); scripts with type application/ld+json are kind "data" and never executable.
