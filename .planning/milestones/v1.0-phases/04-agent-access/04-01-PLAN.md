<interfaces>
Claude Code hook contract (code.claude.com/docs/en/hooks, checked during planning): a PreToolUse command hook receives JSON on stdin with tool_name (for this server, mcp__emdash__ followed by the EmDash tool name) and tool_input (the tool arguments). Exit 2 blocks the call and shows stderr to Claude. Exit 0 with no output defers to the normal permission flow. Any other non-zero exit, including Node's exit 1 on a crash or a missing script, is non-blocking, which is why the registered command ends with `|| exit 2`. The command runs in a shell with CLAUDE_PROJECT_DIR set to the project root. A matcher containing characters other than letters, digits, underscore, hyphen, space, comma and pipe is an unanchored JavaScript regex.

Claude Code permission contract (code.claude.com/docs/en/permissions): deny rules run before ask and allow and win across all settings scopes; a bare tool name removes the tool from Claude's context; any mcp__ rule with parentheses is skipped when settings load. PreToolUse hook decisions do not override deny rules.

EmDash 1.3.1 content_update input keys (installed emdash package, MCP server source, read during planning): collection, id, locale, data, slug, status, seo, bylines, taxonomies, publishedAt, migrateBlocks, replaceBlocks, _rev, overrideLock. Draft-only keys (the runtime's DRAFT_ONLY_UPDATE_KEYS, quoted in RESEARCH Finding 3): data, slug, locale, skipRevision, references, actor, migrateBlocks, replaceBlocks. Any other key writes the live row.
EmDash content_create input keys (same source): collection, data, slug, status (enum draft, published), locale, translationOf, migrateBlocks, replaceBlocks, bylines, taxonomies, seo, publishedAt.
Taxonomy definition tools (same source): taxonomy_create, taxonomy_update and taxonomy_delete change which collections a taxonomy applies to, its hierarchy, or delete it with every term and assignment; each needs only taxonomies:manage, which content:write implies.

- The `.mcp.json` URL carries a localhost default (RESEARCH Open Question 4) so a clean local session needs only EMDASH_TOKEN; EMDASH_MCP_URL still overrides it per environment (D-09).
