<interfaces>
Dokploy facts from the documentation, to be shown by the user's run and not assumed after it: Volume Backups take a destination, a cron schedule, a prefix and a Turn off Container switch (stop, copy, restart); Restore Volume takes a destination, a backup and a NEW volume name that must not exist; the R2 destination fields are Access Key Id, Secret Access Key, Region, Endpoint and Bucket with a connection test.
The runtime image is node:24-alpine with BusyBox, so wget and md5sum exist; it listens on 0.0.0.0:4321. 127.0.0.1 is used instead of localhost because BusyBox wget may try the IPv6 address first. The pages are deterministic: parity against the baseline is 17/17 identical across days (05-03 C6), so equal content gives equal hashes.
