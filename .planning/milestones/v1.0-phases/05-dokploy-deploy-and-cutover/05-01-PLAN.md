- `export async function check(base)`: `@param {string} base`, `@returns {Promise<string | null>}`. Requests, in order, `/`, `/projects/`, then `/projects/<slug>/` for the first slug the crawl pattern captures from the /projects/ body. Each request: `fetch(new URL(path, base), { redirect: "manual", signal: AbortSignal.timeout(FETCH_TIMEOUT_MS) })`.
- Reasons, exact text: `<path> answered <status>` (for example `/ answered 500`, `/ answered 301`, `/projects/alpha/ answered 500`); `no project link on /projects/`; `<path> request failed: <error message>` when fetch throws.
- CLI: `node scripts/smoke-test.mjs BASE_URL [--attempts N] [--delay-ms MS]`; defaults 10 attempts, 15000 ms; BASE_URL must parse with `new URL` and use http: or https:; N and MS positive integers. Per failed attempt print `smoke-test: attempt <i>/<n> failed: <reason>`; on success print `smoke-test: PASS`; after the last failure print `smoke-test: FAIL (<reason>)`. Exit 0, 1, or 2 for bad arguments. The CLI block runs only when `import.meta.url === pathToFileURL(process.argv[1]).href`, so importing `check` runs nothing.

scripts/dokploy-deploy.mjs contract (new):

- `export function latestDeployment(body)`: `@param {unknown} body`, `@returns {{ id: string, status: string } | null}`. Accepts an array, or an object whose `data` is an array; null for an empty list or any other shape. Picks the item with the greatest `Date.parse(createdAt)` when every item has a parseable createdAt, otherwise the first item. id is `deploymentId` (fallback `id`), status is `status`, both read as strings.
- `export async function deploy(options)`: options `{ url: string, apiKey: string, appId: string, intervalMs: number, timeoutMs: number }`, returns `Promise<string | null>`. Steps: GET `${url}/api/deployment.all?applicationId=<appId>` (URLSearchParams) with headers `accept: application/json` and `x-api-key`; record the newest id as before (or none). POST `${url}/api/application.deploy` with `accept`, `content-type: application/json`, `x-api-key` and body `{"applicationId": appId}`. Then poll the GET every intervalMs until timeoutMs passes; once the newest id differs from before, print each status change; `done` returns null; `error` or `cancelled` returns `deployment <id> ended with status <status>`; any other status keeps waiting. Timeout returns `timed out after <timeoutMs> ms waiting for a new deployment` plus ` (last seen: <id> <status>)` when one was seen. A non-2xx answer returns `deployment.all answered <status>` or `application.deploy answered <status>` (the initial GET failing returns before any POST); a body that latestDeployment cannot read returns `deployment.all did not return a deployment list`; a fetch that throws during polling is printed and the loop continues, while one that throws on the initial GET or the POST returns `<endpoint> request failed: <message>`. Each request uses `AbortSignal.timeout(15000)`. Never print headers, the key, or response bodies.
- CLI: reads DOKPLOY_URL (trailing slashes stripped), DOKPLOY_API_KEY, DOKPLOY_APP_ID; options `--interval-ms N` (default 10000) and `--timeout-ms N` (default 900000). Missing variables: stderr names each missing variable (names only) and exit 2. DOKPLOY_URL must be `https:` unless its hostname is 127.0.0.1, localhost or ::1; otherwise stderr says it must use https and exit 2 without any request. Output lines: `dokploy-deploy: newest deployment before the trigger: <id or none>`, `dokploy-deploy: deploy requested`, `dokploy-deploy: deployment <id> is <status>` on each change, then `dokploy-deploy: PASS` or `dokploy-deploy: FAIL (<reason>)`. Same CLI guard as smoke-test.mjs.

Dokploy API facts used (research Pattern 8, docs.dokploy.com going-production and api pages): auth header `x-api-key`; `POST /api/application.deploy` with JSON body `{ "applicationId": "..." }` queues a build; `GET /api/deployment.all?applicationId=...` lists deployments with deploymentId, status (running, done, error, possibly cancelled) and createdAt. The list order and status set are ASSUMED (A1, A2); plan 05-03 verifies them on the real panel.
